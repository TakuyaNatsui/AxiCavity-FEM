# 誘電体損失 tanδ（摂動法 Q_diel）の解析解検証

誘電体損失（誘電正接 tanδ → Q_diel、摂動法）を、
解析解が既知のピルボックス空洞で検証する。

```bash
python examples/dielectric_loss/run_dielectric_loss.py
```

## 検証内容と結果（2026-07-20 実行、mesh_size=5mm・2次要素）

全充填ピルボックス: 半径 a=50 mm、長さ L=40 mm、ε_r=2.1（PTFE 想定）、tanδ=1e-4。

| 検証項目 | 期待値 | 結果 |
|---|---|---|
| TM010 共振周波数 f = j01·c/(2πa√ε_r) | 1.583597 GHz | 1.583598 GHz（相対誤差 1.4e-7） |
| 一様充填の Q_diel = 1/tanδ | 10000 | 10000.000000000（相対誤差 ~1e-16） |
| 合成則 1/Q = 1/Q_wall + 1/Q_diel | — | 相対誤差 ~2e-16 |
| HOM n=1 の Q_diel = 1/tanδ | 10000 | 全モードで厳密一致 |
| 部分充填（右半分のみ tanδ）の電気的充填率 | 0.5（対称モード） | 0.5000 |

- **一様充填で Q_diel = 1/tanδ が機械精度で成立**するのは実装の構成による
  （Q_diel を「同一求積で評価した 2 積分の比」として計算しており、一様なら
  分子 = 分母/tanδ が恒等的に成立する）。物理的には共振時のエネルギー等分配
  U_E = U_H = U/2 と P_diel = ω ε₀/2 Σ ε_r tanδ ∫|E|² dV の帰結。
- 部分充填の充填率 0.5 は、z=L/2 の対称面で 2 分割した空洞の TM0 モード
  （E-short 両端）が z 方向に対称なため。

## 注意（既知の制約）

- **ε_r を大きくしすぎる（例 9.0）と最低次モードを取り逃すことがある**。
  shift-invert の σ が ε_r に追従しない既知の制約（README の Known constraints）。
  本例では ε_r=2.1 で TM010 が正しく得られることを確認している。
- 摂動法はモード形状の変化を無視する近似（tanδ ≲ 0.05 目安）。
- TM0 の部分充填では E 場が H_φ の微分から再構成されるため、損失配分の収束は
  周波数より 1 次遅い。部分充填の損失評価には 2 次要素を推奨。
