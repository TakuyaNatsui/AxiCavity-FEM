# 精度検証（球形空洞 TM0 / HOM）

半径 50 mm の球形空洞（PEC 球面）の共振周波数を、球ベッセル関数の**解析解**と
比較して FEM の精度を検証するスクリプトです。既定の **7 点求積**で、
軸対称 **TM0**（方位角 m=0）と **HOM**（m=1, 2）の複数モードを対象にします。

## 実行

```bash
python run_accuracy.py
```

出力:
- `accuracy_result.md` … 解析解一覧、モード別の相対誤差・収束次数、まとめ
- `accuracy.png` … 両対数グラフ（横軸=平均メッシュサイズ h、縦軸=相対誤差）

## 仕組み

1. `sphere50mm.gmshproj`（`../../samples/`）を読み、メッシュサイズ lc を
   変えながら 2 次メッシュを生成。
2. 各メッシュで TM0 と HOM(m=1,2) を解く（求積は既定 7 点）。
3. 計算した各モードを**最も近い解析モードに自動マッチ**し、相対誤差を記録。
4. 「平均メッシュサイズ vs 相対誤差」を両対数でプロット。参照の傾き `h^4`
   （2 次要素の固有値誤差の理論次数）を併記。

## 結果の要点（既定設定）

- 最低次 TM0（TM_11）は最細メッシュで**相対誤差 ~1e-8**、多くのモードが 1e-6〜1e-7。
- 下位モードの収束次数は **p≈4**（2 次要素の理論値）で理論とよく一致。
- 要求モードのうち最も高次のものは分解能不足で平坦化することがある
  （グラフで h によらず一定の系列）。より細かいメッシュか少ないモード数にする。

## 再計算（設定変更）

`run_accuracy.py` 冒頭の `CONFIG` セクションを編集して実行し直します。

| 変数 | 意味 |
|---|---|
| `MESH_SIZES_MM` | 試すメッシュサイズ lc [mm] のリスト |
| `ELEM_ORDER` | 要素次数（1 or 2） |
| `TM0_NUM_MODES` / `HOM_NUM_MODES` | 要求モード数 |
| `HOM_ORDERS` | HOM の方位角次数（例 `[1, 2, 3]`） |
| `ANALYTIC_MAX_N` / `ANALYTIC_MAX_P` | 解析解の次数上限（周波数レンジを広げる） |
| `MATCH_TOL` | 最近接マッチの許容相対誤差 |

> 別半径の球なら `SPHERE_RADIUS_M` と gmshproj を差し替えてください。
> 解析解（球ベッセル関数の零点から求める共振周波数）はスクリプト内で計算している
> （本スクリプト内に内蔵）。
